# 2027 考研政治 1000 题 · 沉浸式做题软件（官方全解析版）

专为肖秀荣《2027 考研政治 1000 题》打造的高效、专注、极简现代风本地 Web 刷题系统。收录全部试题，并完整内置官方《答案册》的 **1,148 道标准答案、出处、简析与名师点拨**。

---

## ⚡ 核心功能与特色

- **1,148 道官方全真客观题 + 完整解析**：
  - 覆盖马原、毛中特、习思想、史纲、思修法基全部 5 大学科与所有章节；
  - 每道题目均配备官方【正确答案】、【教材出处】（精准定位精讲精练考点页码）、【核心简析】与【名师点拨/真题映射】。
- **四大刷题模式自由切换**：
  - **⚡ 即做即判（日常主力）**：单选选定即刻判分高亮红绿，多选选完按 Enter / Space 提交判分；自动平滑展开富文本解析面板，看完按 Enter / `→` 切题；做错自动归集错题本。
  - **📝 模考交卷**：全真模拟考场，答题时不剧透答案与解析，做完后一键交卷，生成正确率环形成绩单，并支持逐题复盘。
  - **📖 直接背题**：题目直接展开标准答案与完整解析，适合考前极速过题、强化考点记忆。
  - **❌ 错题专训**：专属针对薄弱错题进行专项突破，做对可一键标记已攻克。
- **全键盘极速操作**：支持 `A / B / C / D`、`1 / 2 / 3 / 4` 选选项，`Enter` 确认/下一题，`E` 开关解析面板，`F` 疑难标记，`M / Tab` 答题卡。
- **移动端与 iPad 无缝畅刷**：同一 Wi-Fi 下移动端浏览器输入局域网地址即可秒变平板刷题神器。

## 🚀 启动方式

### 方式一：双击一键启动（最推荐）
在项目根目录下双击：
👉 **`启动做题软件.bat`**（带控制台日志）
或双击：
👉 **`启动做题软件.vbs`**（无黑框静默启动）

### 方式二：命令行启动
```bash
cd quiz-app
python run_quiz.py
```
- **电脑访问**：`http://localhost:8000`
- **iPad / 手机访问**：`http://<局域网IP>:8000`

## ⌨️ 键盘快捷键一览表

| 按键 | 功能说明 |
| :--- | :--- |
| `A` / `B` / `C` / `D` | 选定或切换对应选项 |
| `1` / `2` / `3` / `4` | 选定对应选项（对应 A/B/C/D） |
| `Enter` 或 `空格` | **单选**：切到下一题；**多选未判**：确认提交判分；**已判题**：切到下一题 |
| `E` | **展开 / 折叠** 当前题目的详细解析面板 |
| `←` 或 `J` | 切换至上一题 |
| `→` 或 `K` | 切换至下一题 |
| `F` | 切换该题「疑难标记 (★)」 |
| `M` 或 `Tab` | 打开 / 关闭答题卡全景抽屉 |
| `Esc` | 关闭弹窗或答题卡 |
